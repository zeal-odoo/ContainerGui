# Container GUI v2.17.0

## 中文

此版本为 Container GUI 增加安全、非阻塞的版本更新提醒：

- 页面可用后每天自动检查一次 GitHub 最新稳定版，也可从顶部手动检查。
- 发现新版时显示当前版本与最新版本，并提供官方 GitHub Release 下载入口。
- 自动检查只提醒，不会自动下载、安装或执行 PKG。
- GitHub 暂时不可用不会阻断容器列表或管理操作。
- 更新流程支持中文和 English，并延续现有 Material 3 动效及无障碍回退。

下载 `ContainerGUI-2.17.0-arm64.pkg` 后，请使用随附的 `.sha256` 文件校验完整性。

> 当前 PKG 未使用 Developer ID Installer 证书签名，也尚未经过 Apple 公证。请只从本仓库 Release 下载，并在安装前核对 SHA-256。

## English

This release adds a safe, non-blocking update reminder to Container GUI:

- Check the latest stable GitHub Release once per day after the page becomes usable, or check manually from the header.
- Show the current and latest versions when an update is available, with a link to the official GitHub Release.
- Automatic checks notify only; they never download, install, or execute a PKG.
- A temporary GitHub failure does not block container listing or management.
- The update flow is localized in Chinese and English and follows the existing Material 3 motion and accessibility behavior.

After downloading `ContainerGUI-2.17.0-arm64.pkg`, verify it with the accompanying `.sha256` file.

> The current PKG is not signed with a Developer ID Installer certificate and has not been notarized by Apple. Download it only from this repository's Release and verify its SHA-256 before installation.
