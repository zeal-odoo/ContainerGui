Create container

      
创建容器

      
填写常用参数。端口只会绑定到本机 127.0.0.1，默认创建后不启动。

      

        
        
        
        
      

      
      

        目录映射
        
本机共享目录

        
用于本机与容器之间读写和传输文件；留空则不挂载。

        

          
          
        

      

      

        Odoo 数据库连接
        
仅配置数据库地址与端口；数据库用户和密码仍可在下方环境变量中填写。

        

          
          
        

      

      

        SSH 快速配置
        
        

          
自动安装并启动 SSH，只绑定到 127.0.0.1；密码登录始终禁用。容器重启后会自动恢复。

          
          
高权限选项：公钥将授权给 root，密码登录保持禁用；未勾选时继续创建普通用户。

          

            
            
          

          
          
          

            
            
          

          
密钥对只在当前浏览器生成；公钥自动填入，私钥只下载一次且不会上传或保存。

        

      

      
      
      
      
适用于 Ubuntu 等没有常驻进程的镜像；GUI 固定使用 /bin/bash -lc 和 exec sleep infinity。启用 SSH 时无需选择。
