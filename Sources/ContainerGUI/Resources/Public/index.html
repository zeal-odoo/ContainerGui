Create container

      
创建容器

      
填写常用参数。端口只会绑定到本机 127.0.0.1，默认创建后不启动。

      

        
        
        
        
      

      
      

        SSH 快速配置
        
        

          
自动安装并启动 SSH，只绑定到 127.0.0.1；不启用密码或 root 登录。容器重启后会自动恢复。

          

            
            
          

          
          
          

            
            
          

          
密钥对只在当前浏览器生成；公钥自动填入，私钥只下载一次且不会上传或保存。

        

      

      
      
      
      
适用于 Ubuntu 等没有常驻进程的镜像；GUI 固定使用 /bin/bash -lc 和 exec sleep infinity。启用 SSH 时无需选择。
