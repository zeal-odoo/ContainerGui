# Feature Specification: SSH 快速配置

**Feature Branch**: `main`

**Created**: 2026-08-30

**Status**: Draft

**Input**: User description: "在创建容器时通过 GUI 简单开启 SSH，自定义宿主机端口，并保证容器重启后 SSH 自动恢复。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一键配置密钥 SSH (Priority: P1)

本机用户创建容器时，可以勾选“启用 SSH”，填写宿主机端口、登录用户名和公钥，不需要手工编写安装命令、环境变量或进程参数。

**Why this priority**: 这是用户减少 CLI 和手工配置的核心目标，也是能够实际连接容器的最小闭环。

**Independent Test**: 在创建表单启用 SSH，保留默认端口和用户名并提供有效公钥；创建后页面显示完整连接命令，且只能从本机地址连接。

**Acceptance Scenarios**:

1. **Given** 用户选择一个受支持的 Linux 镜像，**When** 启用 SSH、提供有效公钥并创建容器，**Then** 系统自动配置容器端口 22、密钥登录用户和持续运行的 SSH 服务。
2. **Given** 用户启用 SSH，**When** 未修改默认值，**Then** 宿主机端口为 2222、登录用户名为 `dev`，页面明确显示本机连接命令。
3. **Given** 用户启用 SSH，**When** 选择一个 `.pub` 公钥文件，**Then** 表单读取并校验公钥，而不要求用户手工复制安装脚本。

---

### User Story 2 - 自定义端口并在重启后恢复 (Priority: P2)

本机用户可以为不同容器选择不同的高位宿主机端口，并在停止、再次启动容器后继续使用相同的连接方式。

**Why this priority**: 自定义端口避免多个 SSH 容器冲突，自动恢复使配置在日常启停中真正可用。

**Independent Test**: 创建使用自定义端口的 SSH 容器，记录连接命令；停止并重新启动同一容器后，确认端口、用户名和连接命令不变，SSH 状态重新变为可连接。

**Acceptance Scenarios**:

1. **Given** 用户选择 1024 至 65535 之间的未占用端口，**When** 创建 SSH 容器，**Then** 该端口仅绑定本机地址并映射到容器端口 22。
2. **Given** SSH 容器已经成功创建，**When** 用户停止并重新启动该容器，**Then** SSH 服务自动启动且原连接命令保持不变。
3. **Given** 容器正在首次安装或启动 SSH，**When** 用户查看容器详情，**Then** 页面显示“初始化中”“可连接”或明确的失败状态，而不把容器运行状态等同于 SSH 已就绪。

---

### User Story 3 - 安全校验与可理解错误 (Priority: P3)

本机用户在端口、用户名、公钥或镜像不适合时，能在提交前或创建失败后看到具体原因，不会得到一个表面成功但无法登录的容器。

**Why this priority**: SSH 涉及本机端口和访问凭据，清晰校验可避免不安全默认值和难以诊断的失败。

**Independent Test**: 分别提交低位端口、重复端口、非法用户名、无效公钥和无法安装 SSH 的镜像，确认请求被拒绝或状态明确失败，且真实容器状态不会被测试修改。

**Acceptance Scenarios**:

1. **Given** 用户输入低于 1024、超过 65535、已重复映射或格式错误的端口，**When** 提交创建，**Then** 系统拒绝请求并指出端口问题。
2. **Given** 用户输入无效用户名或非公钥文本，**When** 提交创建，**Then** 系统拒绝请求且不执行容器变更。
3. **Given** SSH 初始化失败，**When** 用户查看状态，**Then** 页面保留失败摘要和日志入口，不显示“可连接”。
4. **Given** SSH 已启用，**When** 用户查看配置或操作记录，**Then** 页面不回显完整公钥内容，也不启用密码或 root 登录。

### Edge Cases

- SSH 宿主机端口与用户手工填写的普通端口映射重复时，提交必须失败并定位冲突行。
- 同一宿主机端口已被其他进程占用时，创建或启动失败必须保留实际错误摘要，不得显示为 SSH 就绪。
- 公钥文件为空、包含多行、超过合理长度或算法不受支持时，提交必须失败。
- 镜像没有受支持的软件包管理能力或首次安装期间网络不可用时，SSH 状态必须变为失败或保持未就绪，并可查看日志。
- 页面刷新、服务重启或外部 CLI 操作后，SSH 状态和连接信息必须从容器当前配置重新读取，不依赖浏览器内存。
- 删除并重新创建同名容器不保证服务器主机密钥不变；界面必须避免承诺其身份指纹永久不变。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 创建容器表单 MUST 提供一个默认关闭的“启用 SSH”选项。
- **FR-002**: 启用 SSH 后，系统 MUST 提供宿主机端口、登录用户名和 SSH 公钥输入；默认端口为 2222，默认用户名为 `dev`。
- **FR-003**: 用户 MUST 能粘贴公钥或选择一个 `.pub` 文件，且选择文件后仍能检查和修改读取结果。
- **FR-004**: 系统 MUST 将 SSH 宿主机端口限制为 1024 至 65535，并只绑定到 `127.0.0.1`，容器目标端口固定为 22。
- **FR-005**: 系统 MUST 拒绝与同一次创建请求中其他端口映射重复的 SSH 宿主机端口。
- **FR-006**: 系统 MUST 校验登录用户名和单行 SSH 公钥格式，并在任何真实变更前拒绝无效输入。
- **FR-007**: SSH 配置 MUST 只允许公钥登录，MUST 禁用密码登录和 root 登录。
- **FR-008**: 系统 MUST 自动完成受支持镜像内 SSH 服务的首次初始化，并使 SSH 服务成为容器持续运行的主服务。
- **FR-009**: 同一容器停止后再次启动时，系统 MUST 自动恢复 SSH 服务，并保留端口、用户名、授权公钥和现有服务器主机密钥。
- **FR-010**: 创建成功后，系统 MUST 显示可复制的连接命令，并在容器详情中显示 SSH 的未配置、初始化中、可连接或失败状态。
- **FR-011**: SSH 就绪判定 MUST 独立于容器“运行中”状态；仅当本机映射端口可建立 SSH 连接时才能显示“可连接”。
- **FR-012**: 页面刷新和服务重启后，系统 MUST 从当前容器配置重新生成 SSH 连接信息和状态，不得依赖影子数据库或仅存在于浏览器的状态。
- **FR-013**: 操作摘要和详情 MUST NOT 回显完整公钥；错误状态 MUST 提供可理解摘要和容器日志入口。
- **FR-014**: 未启用 SSH 时，现有创建容器流程和手工端口、环境变量、进程参数行为 MUST 保持不变。
- **FR-015**: 该功能 MUST NOT 自动改写现有容器；现有未配置 SSH 的容器需要重新创建才能使用快速配置。

### Key Entities

- **SSH 创建配置**: 某次容器创建请求中的可选设置，包括宿主机端口、容器端口 22、登录用户名和授权公钥。
- **SSH 连接信息**: 从当前容器配置派生的本机地址、宿主机端口、登录用户名和可复制连接命令。
- **SSH 运行状态**: 未配置、初始化中、可连接或失败；与容器本身的运行/停止状态相关但不等同。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户在已有公钥的前提下，可在 60 秒内完成 SSH 配置表单且无需编写任何安装命令。
- **SC-002**: 所有无效端口、用户名和公钥样本都在执行真实容器变更前被拒绝，并显示对应字段错误。
- **SC-003**: 对同一 SSH 容器执行一次停止和再次启动后，100% 保留原连接命令，并在服务就绪后恢复为“可连接”。
- **SC-004**: 页面刷新或管理服务重启后，100% 的 SSH 容器仍能重新显示相同的端口、用户名和连接命令。
- **SC-005**: 所有 SSH 端口只接受经 `127.0.0.1` 的本机连接，且密码登录和 root 登录在验收样本中均被拒绝。
- **SC-006**: 未启用 SSH 的现有创建、启动、停止、删除和日志流程全部通过回归测试。

## Assumptions

- 首期支持可通过 Debian/Ubuntu 系列软件包管理方式安装 OpenSSH Server 的镜像；其他镜像会得到明确的不支持或初始化失败信息。
- 用户已拥有一个有效 SSH 公钥；本功能不生成或保管私钥。
- 默认登录用户名为 `dev`，用户可在安全用户名规则内修改。
- SSH 仅用于本机开发，不开放局域网或互联网访问；远程访问、密码认证和 root 登录不在本次范围。
- 快速配置只应用于新建容器，不迁移或修改现有容器。
