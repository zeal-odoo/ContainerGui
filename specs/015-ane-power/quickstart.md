# Validation guide

1. Run `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test` and `node --test Tests/Frontend/*.mjs`.
2. Build release, request `/api/v1/system/ane` twice 5 seconds apart: sampling then ready on supported machine; no-store; finite watts; utilization always null. Unsupported platforms return unavailable without root.
3. Open container page: independent host ANE panel, live watts, sample window and honest scope. Verify Chinese/English, 390px, inactive tab, HTTP failure clearing and recovery. No container operations.
4. Confirm AI remains off and no worker spawned by ANE monitoring. Record CLI version and unchanged running containers.
5. Read back installed version/resources after user-level GUI deployment, run diff check, bump minor version and local commit. No push or PKG.
