# Feature Specification: 整机 ANE 估算功耗

**Feature Branch**: `codex/local-ai-logs`
**Created**: 2026-09-08
**Status**: Ready for implementation
**Input**: 用户确认显示整机 ANE 功耗（W），使用率显示不可用，不将功耗或通电时间冒充计算使用率。

## User Scenarios & Testing

### User Story 1 - 查看准确口径的 ANE 指标 (Priority: P1)

用户在容器页查看本机 ANE 的估算功耗，了解本机 AI 活动的资源影响。
**Why this priority**: 提供可读取的真实指标，避免虚假的计算使用率。
**Independent Test**: 输入固定能量变化及采样时长，页面显示正确瓦数和整机范围说明。
**Acceptance Scenarios**:
1. **Given** 支持读取的机器，**When** 页面持续可见，**Then** 功耗每约 5 秒更新，注明估算、整机所有应用和采样窗口。
2. **Given** 首次打开或离开后返回，**When** 尚未取得两次有效采样，**Then** 显示采样中而不是零。
3. **Given** 没有容器或 AI 已关闭，**When** 刷新，**Then** ANE 仍可独立显示且不会启动模型。

### User Story 2 - 明确失败与兼容状态 (Priority: P2)

用户可以区分空闲零功耗与系统无法读取，使用率始终说明不可用。
**Why this priority**: 监控失败不能变成误导性数值或破坏主要功能。
**Independent Test**: 模拟计数器重置、缺失、请求失败和恢复，确认旧值清除、其他功能正常。
**Acceptance Scenarios**:
1. **Given** 不支持的系统或无有效数据，**When** 查询，**Then** 功耗为不可用并给出安全原因，不显示旧数值。
2. **Given** 有效零能量增量，**When** 采样，**Then** 可显示 0.00 W，但计算使用率仍不可用。
3. **Given** 中文、English 或 390px 屏幕，**When** 浏览指标，**Then** 口径清楚且无横向溢出。

### Edge Cases

缺失、重复或未知单位的通道；负数或重置计数器；过短、过长或异常采样时间；多窗口请求；页面隐藏；睡眠恢复；容器 CLI 关闭或报错。指标不执行容器命令，不采集日志或秘密。

## Requirements

### Functional Requirements

- **FR-001**: 显示独立的整机 ANE 估算功耗（W），不纳入容器 CPU/内存合计。
- **FR-002**: 使用率显示“不可用”，不从功耗、通电时间或 AI 开关换算百分比。
- **FR-003**: 显示采样中、可用、不可用以及采样窗口；无效读数必须清除旧值。
- **FR-004**: 普通用户无需密码、权限提升、驱动安装、模型启动或新增外部服务。
- **FR-005**: 可见容器页每约 5 秒采样，隐藏页停止轮询；多窗口不得制造不受限后台工作。
- **FR-006**: 中英文、键盘可访问和窄屏布局沿用现有简洁风格。
- **FR-007**: 先写固定样本与接口/前端失败用例，再实现；真实验证只读且不改变容器。

### Key Entities

- **ANE 功耗样本**: 状态、瓦数、读取时间、采样时长和不可用原因；只在内存短期保存。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 支持机器在两次正常刷新内显示瓦数；所有无效数据用例均不显示伪造的 0 或百分比。
- **SC-002**: 页面显示范围、估算含义及使用率不可用的说明，中文/英文在 390px 和桌面均无溢出。
- **SC-003**: 关闭 AI 后没有模型进程；ANE 监控不改变用户容器状态。
- **SC-004**: 自动测试、真实只读接口及浏览器验证通过，递增应用版本并创建聚焦本地提交。

## Assumptions

- 用户已确认替代口径，不需要进一步需求澄清。
- 基线为 Apple Silicon/macOS 26；不同硬件或系统读取失败时明确降级，不承诺所有机型可读取。
- 估算功耗不用于不同设备的精确能耗比较；不声称可归因 Container GUI。
- 本任务不发布 GitHub/PKG，不更改 AI 模型生命周期。
