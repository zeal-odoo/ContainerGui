# Implementation Plan: 克制玻璃表面与远程镜像分页

## Summary

保持现有原生 HTML/CSS/JavaScript 架构；远程仓库、标签和本机镜像表格统一使用每页 10 条的数字分页。本机镜像只在显示层切片，完整数据继续用于创建表单和安全判断。

## Constraints

- 不新增前端依赖或构建链。
- 不改变容器、镜像及远程搜索 API 契约。
- 浏览器验收不得执行创建、拉取、删除或生命周期操作。
- 所有透明效果必须有无障碍与兼容回退。

## Implementation

1. 先添加 glass、详情 toggle、分页替换和版本失败测试。
2. 在 `app.css` 增加 glass 令牌、限定表面与实色回退。
3. 在 `app.js` 同步详情按钮状态，并把远程结果改为当前页替换。
4. 在 `index.html` 增加两组上一页/数字页码/下一页控件，并复用同一页码窗口算法。
5. 将版本递增至 2.13.0，完成自动化及真实浏览器只读验收。
6. 单一提交推送 `origin/main` 并核对远端提交。
