# Container GUI v2.26.2

## 中文

兼容 Apple Container 1.6.1，并保留现有容器管理及连接配置功能。

- 识别 Container 1.6.x；继续支持 1.3.x、1.4.x（从 1.4.1 起）与 1.5.x。未验证的 1.7.x 和其他主版本仍不作为兼容版本。
- 保留结构化 CLI 命令、旧版输出解析和客户端/服务端独立版本显示，支持升级期间的新客户端与旧服务端组合。
- 修复同一镜像内容对应多个标签或摘要引用时，镜像列表无法读取的问题。删除操作优先匹配完整引用，保留其他别名；含糊的内容 ID 会在执行前被拒绝。
- 同步 GUI 版本和页面资源缓存标识为 2.26.2。
- 342 项 Swift 测试中 3 项按默认设置跳过，其余通过，包含官方 1.6.1 CLI 的实机只读检查；95 项前端测试全部通过。详细验证及实时环境边界见 [1.6.1 兼容性记录](https://github.com/zeal-odoo/ContainerGui/blob/v2.26.2/specs/001-container-web-gui/verification/container-1.6.1.md)。

包内程序已完成 1.6.1 CLI / 1.5.0 服务端的隔离容器全流程验证。本机 1.6.1 服务端升级按用户要求等待数据库操作完成，届时再验收同版本组合。首次创建前请先完成官方 CLI 的系统镜像准备。

安装包适用于 Apple silicon、macOS 26 或以上，Apple Container 需另行安装。引擎升级请使用 [Apple 官方 1.6.1 安装包](https://github.com/apple/container/releases/tag/1.6.1)，先等待数据库恢复、建库等操作结束并安排容器停机，再安装并核对 CLI 与服务端版本。GUI 不会自动安装或重启引擎。

下载 `ContainerGUI-2.26.2-arm64.pkg` 及同名 `.sha256` 文件，在同一目录执行：

```sh
shasum -a 256 -c ContainerGUI-2.26.2-arm64.pkg.sha256
```

安装包**未使用 Developer ID Installer 签名，也未经过 Apple 公证**；可执行文件仅使用 ad-hoc 签名。

## English

This release supports Apple Container 1.6.1 while retaining existing container management and Connection configuration.

- Recognizes Container 1.6.x and retains 1.3.x, 1.4.x from 1.4.1 onward, and 1.5.x. Unverified 1.7.x and other major versions remain unsupported.
- Preserves structured CLI commands, legacy output parsing, and independent client/server version reporting, including a new client with an older server during an upgrade.
- Fixes image-list parsing when multiple tags or digest references share one content ID. Deletion prefers the exact reference and preserves other aliases; ambiguous content IDs are rejected before mutation.
- Synchronizes the GUI version and page resource cache keys to 2.26.2.
- The Swift suite has 342 tests, three opt-in skips, and zero failures, including live read-only checks with the official 1.6.1 CLI; all 95 frontend tests pass. See the [1.6.1 compatibility record](https://github.com/zeal-odoo/ContainerGui/blob/v2.26.2/specs/001-container-web-gui/verification/container-1.6.1.md) for detailed verification and live-environment limits.

The packaged runtime passed isolated lifecycle, networking, mount, log and metrics checks with the 1.6.1 CLI and 1.5.0 daemon. Local 1.6.1 daemon installation and same-version live acceptance are deferred until ongoing database work finishes. Prepare the official CLI's system images before first creation.

The installer requires Apple silicon and macOS 26 or later. Install Apple Container separately using the [official Apple 1.6.1 installer](https://github.com/apple/container/releases/tag/1.6.1). Wait for database restores and database creation to finish, schedule container downtime, then install and verify both CLI and server versions. The GUI does not automatically install or restart the engine.

Download `ContainerGUI-2.26.2-arm64.pkg` and its `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c ContainerGUI-2.26.2-arm64.pkg.sha256
```

The installer is **not Developer ID Installer signed or Apple notarized**; its executable is ad-hoc signed only.
