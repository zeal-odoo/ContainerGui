# Container GUI v2.28.2

## 中文

兼容 Apple Container 1.7.1，并将此前本机完成的容器列表改进一起发布。

- 容器按“运行中”和“未运行”上下分组；没有容器的分组自动隐藏。
- 每行提供启动/停止图标。停止采用正常停止方式，保留目标确认与实际状态回读。
- 列表和详情显示实际端口映射（本机地址和端口 → 容器端口/协议），没有映射时明确显示“未映射”。创建容器时可自定义本机回环端口映射。
- 支持 Container 1.7.x（从 1.7.1 起），保留 1.3.x、1.4.x（从 1.4.1 起）、1.5.x 和 1.6.x。兼容新版统计字段，维持现有 CPU 采样和显示口径。
- 分别读取命令行与后台服务版本。GUI 不会自动升级或重启 Container 引擎。
- 2.28.2 同步发布说明、下载入口、应用版本及页面资源缓存标识；功能与已验证的 2.28.1 一致。

验证包含 347 项 Swift 检查（3 项可选检查跳过，零失败）、104 项前端检查，以及临时容器的创建、启动、重启、停止、删除、日志、资源采样和端口访问。实机环境为 **1.7.1 CLI / 1.6.1 后台服务**；1.7.1 服务端输出通过固定样本测试覆盖，尚未进行同版本服务端的实机验收。详情见 [1.7.1 兼容性记录](https://github.com/zeal-odoo/ContainerGui/blob/v2.28.2/specs/001-container-web-gui/verification/container-1.7.1.md)。

安装包适用于 Apple silicon、macOS 26 或以上，Apple Container 需另行安装。下载 `ContainerGUI-2.28.2-arm64.pkg` 和同名 `.sha256` 文件，在同一目录执行：

```sh
shasum -a 256 -c ContainerGUI-2.28.2-arm64.pkg.sha256
```

安装包**未使用 Developer ID Installer 签名，也未经过 Apple 公证**；可执行文件仅使用 ad-hoc 签名。

## English

This release supports Apple Container 1.7.1 and publishes the container-list improvements previously available locally.

- Running and inactive containers appear in vertically stacked groups. Empty groups are hidden.
- Each row has start/stop icons. Stop is graceful, with target confirmation and authoritative state readback.
- Lists and details show actual published ports (host address and port → container port/protocol), or an explicit unmapped state. Custom loopback port mappings are available when creating a container.
- Supports Container 1.7.x from 1.7.1 onward, retaining 1.3.x, 1.4.x from 1.4.1 onward, 1.5.x and 1.6.x. New statistics fields preserve the existing CPU sampling and display semantics.
- Reads CLI and server versions independently. The GUI does not automatically upgrade or restart the Container engine.
- Version 2.28.2 synchronizes release documentation, download links, the app version and resource cache keys. Functional behavior is unchanged from the validated 2.28.1.

Validation includes 347 Swift checks (three opt-in skips, zero failures), 104 frontend checks, and a temporary container's create/start/restart/stop/delete, logs, resource samples and published-port access. Live validation used **CLI 1.7.1 with server 1.6.1**; server 1.7.1 output is covered by fixtures, not a live same-version server run. See the [1.7.1 compatibility record](https://github.com/zeal-odoo/ContainerGui/blob/v2.28.2/specs/001-container-web-gui/verification/container-1.7.1.md) for details.

The installer requires Apple silicon and macOS 26 or later. Install Apple Container separately. Download `ContainerGUI-2.28.2-arm64.pkg` and its `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c ContainerGUI-2.28.2-arm64.pkg.sha256
```

The installer is **not Developer ID Installer signed or Apple notarized**; its executable is ad-hoc signed only.
