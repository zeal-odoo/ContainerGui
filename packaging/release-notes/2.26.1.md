# Container GUI v2.26.1

## 中文

此版本正式发布 v2.25.0/v2.26.0 开发的连接配置功能，并同步安装包版本及中英文说明。

- 所有容器详情新增“连接配置”入口；未识别或不适用的配置会说明原因并禁用保存，不会添加应用不支持的数据库参数。
- 已有 Odoo 可修改数据库地址和端口，或一次性填入运行中 PostgreSQL 的当前 IPv4 地址。
- 支持已识别的 `/app-config/app.env` 中已有的 `DB_HOST`/`DB_PORT`，以及 Nginx 直接 HTTP(S) `proxy_pass` 后端；每次只修改选中的后端，保留协议、URI、其他端口及认证/TLS 配置。
- 保存前创建 0600 私有备份、校验完整文件版本，保存后独立回读。保留密码等其他内容，不迁移、不自动启停或重载，不将保存成功当作连接成功。
- 延续 Apple Container 1.3.x、1.4.x（从 1.4.1 起）、1.5.x 及 macOS 27 兼容支持。安装包适用于 Apple silicon、macOS 26 或以上；Apple Container 需另行安装。

限制与验证：Nginx 单文件挂载只允许在已停止/已创建状态编辑；动态地址、upstream 组、模板、额外 include 和自定义启动覆盖不猜测。336 项 Swift 测试中 4 项按默认设置跳过，其余通过；95 项前端测试通过。真实界面已验证通用入口与中英文限制提示，但外接磁盘上的完整配置读取/草稿刷新验收仍待 macOS 系统读取放行；请自行确认宗卷访问提示，程序不会绕过系统权限。

下载 `ContainerGUI-2.26.1-arm64.pkg` 及同名 `.sha256` 文件，在同一目录执行：

```sh
shasum -a 256 -c ContainerGUI-2.26.1-arm64.pkg.sha256
```

安装包**未使用 Developer ID Installer 签名，也未经过 Apple 公证**；可执行文件仅使用 ad-hoc 签名。这不代表 macOS 已验证发布者身份。请仅从本仓库下载，核对校验值后再自行确认安装。

## English

This release publishes the connection features developed in v2.25.0/v2.26.0 and synchronizes the installer version and bilingual documentation.

- Every container detail has Connection configuration. Unrecognized or inapplicable forms show a reason and disable saving without inventing application parameters.
- Edit an existing Odoo database address/port or fill the currently observed IPv4 of a running PostgreSQL container once.
- Edit existing `DB_HOST`/`DB_PORT` in a recognized `/app-config/app.env`, or select one direct HTTP(S) Nginx `proxy_pass` backend. Protocol, URI, other ports and authentication/TLS settings remain unchanged.
- Saves create a private 0600 backup, check a whole-file revision, and independently read back the result. Credentials are preserved; no migration, automatic lifecycle action, reload or connectivity test is performed.
- Apple Container 1.3.x, 1.4.x from 1.4.1 onward, 1.5.x and macOS 27 compatibility is retained. The installer requires Apple silicon and macOS 26 or later; install Apple Container separately.

Limits and validation: single-file Nginx mounts can only be edited while stopped/created. Dynamic targets, upstream groups, templates, additional includes and custom startup overrides are not guessed. The Swift suite has 336 tests with 4 opt-in skips and zero failures; all 95 frontend tests pass. The live universal entry and bilingual restrictions were checked, but full mounted-config/draft-refresh acceptance on the external volume awaits release of the macOS file-open operation. Review volume-access prompts yourself; the application never bypasses OS permissions.

Download `ContainerGUI-2.26.1-arm64.pkg` and its `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c ContainerGUI-2.26.1-arm64.pkg.sha256
```

The installer is **not Developer ID Installer signed or Apple notarized**; its executable is ad-hoc signed only. This does not establish a verified publisher identity. Download only from this repository, verify the checksum, and review the installation yourself.
